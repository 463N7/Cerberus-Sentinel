Recover or resume an installation

If the screen is blank after preparation, that is expected: the temporary bridge is running.

To enter S3 download mode: hold S3 BOOT, tap S3 RESET, then release BOOT. Use the S3 controls, not the C5 controls. Select the USB JTAG/serial device when asked.

Restoring only the S3 does not update or verify the C5. A complete install and startup check are still required.
